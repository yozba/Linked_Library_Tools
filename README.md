# Linked Library Tools

Blender 5.x向けのリンクデータ管理ツールです。

- **Batch Remap User**：Outlinerで選択した複数のデータブロックを、外部Blendファイル内の同名・同種のデータブロックへ一括Remapします。
- **Find Missing Linked Libraries**：選択なしで、欠損したLinked Libraryを指定のBlendファイルへまとめて付け替えます。

Remapは **View Layer / Scenes / Blender File / Orphan Data** などの表示モードに対応し、移行先がまだLinkされていなくても使えます。
